REGISTRO TERRITORIOS - Android V1

Nombre: Registro Territorios
Package ID: cl.newweb.registroterritorios
Web inicial: https://territorios.newweb.cl/

Incluye:
- WebView a pantalla completa
- JavaScript / almacenamiento web / cookies
- Navegación atrás dentro de la app
- Selector de archivos desde formularios web
- Descargas
- Manejo de enlaces externos no-http(s)
- Pantalla de error sin Internet con reintento
- Ícono personalizado

Notificaciones push:
La V1 deja declarada la permission POST_NOTIFICATIONS, pero la integración push necesita asociar el proyecto con un proveedor (Firebase Cloud Messaging / OneSignal) y sus claves. No se incluyen claves genéricas por seguridad.
